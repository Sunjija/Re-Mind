# Re:Mind

마음과 마음 사이, 대화가 다시 이어지도록.

Re:Mind 서비스 기획 발표자료입니다. 공유 링크로 접속하면 화면 크기와 터치 환경을 확인해 모바일판 또는 PC판을 자동으로 엽니다.

## 보기

- 자동 선택: `outputs/index.html`
- PC 발표자료: `outputs/remind_product_plan_v0.1.html`
- 모바일 발표자료: `outputs/remind_product_plan_mobile_v0.1.html`

주소 뒤에 `?view=mobile` 또는 `?view=desktop`을 붙이면 원하는 화면을 직접 선택할 수 있습니다.
