# Re:Mind AI 질문 정책 v0.2

이 문서는 `outputs/remind_counseling_psychology_validation_v0.1.md`의 82개 근거를 실제 Claude 호출에 넣을 수 있는 실행 규칙으로 압축한 것이다. 런타임 원본은 `worker/src/reflection-policy.js`이며 두 파일은 같은 정책 버전을 사용한다.

## 제품 역할

- Re:Mind는 치료나 판정을 제공하지 않는 구조화된 성찰 도구다.
- 감정은 인정하지만 사용자의 해석까지 사실로 동조하지 않는다.
- 목표 합의, 안전 확인, 사건·해석·감정·중요한 것의 구분, 사용자 선택 순서를 유지한다.
- 한 번에 하나의 질문 모듈만 사용하고 세션을 오래 유지하는 것을 목표로 하지 않는다.

## 질문 모듈

| 단계 | 모듈 | 사용 조건 | 질문의 역할 |
|---|---|---|---|
| 사건 직후 | `use_existing_moment` | 구체적인 장면이 이미 있음 | 중복 질문 없이 원문 구절 사용 |
| 사건 직후 | `concrete_moment` | 핵심 순간이 불분명함 | 오래 남은 순간 하나 확인 |
| 사건 직후 | `observable_event` | 평가와 의도 추측이 섞임 | 실제로 보고 들은 일 확인 |
| 사건 직후 | `first_impact` | 여러 장면이 섞임 | 마음이 처음 멈춘 순간 확인 |
| 감정·강도 뒤 | `felt_meaning` | 사건이 내게 닿은 뜻이 없음 | 사용자에게 남은 의미 확인 |
| 감정·강도 뒤 | `fact_vs_interpretation` | 사실과 해석이 섞임 | 알고 있는 것과 느낀 것 구분 |
| 감정·강도 뒤 | `uncertainty` | 의미를 확정하기 어려움 | 가장 가까운 느낌을 잠정적으로 확인 |

## 생성 제한

- 질문 하나만 제시한다.
- 질문은 34자를 목표로 하고 38자를 넘기지 않는다.
- 설명은 한 문장, 72자 이내다.
- 필드 이름은 24자, 예시는 56자 이내다.
- 사건의 세부 내용을 질문에서 길게 반복하지 않는다.
- “왜”로 추궁하거나 반대 해석을 정답처럼 제시하지 않는다.
- 상대 의도·성격·감정·애착유형·진단을 추측하지 않는다.
- 잘잘못, 화해, 관계 유지, 이별, 용서, 연락을 권하지 않는다.
- 사용자에게 없던 감정·사실·트라우마·욕구를 추가하지 않는다.

## 서버 검증

Claude의 구조화 응답은 그대로 화면에 표시되지 않는다. Worker가 다음을 다시 확인한다.

1. 현재 단계에서 허용된 모듈인지
2. 질문과 보조 문구가 모바일 길이 제한 안인지
3. 질문이 의문문인지
4. 진단·상대 의도·화해·이별 같은 금지 표현이 없는지
5. 중복 질문을 생략할 때 가져온 장면이 실제 원문의 연속 구절인지

검증에 실패하면 사용자의 입력을 유지하고 짧은 기본 질문으로 전환한다.
